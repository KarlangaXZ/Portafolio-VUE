# Game covers

Place your authorized local cover images here:

- `wow.webp`
- `diablo-iv.webp`
- `apex-legends.webp`
- `forza-horizon.webp`

Recommended: portrait images, at least 600 × 800 pixels. The cards crop with `object-fit: cover`, so keep important artwork near the center. Text is rendered separately.

Missing or unreadable images use a CSS placeholder. No external images are requested. Vite discovers these files through `src/data/games.ts`; restart the dev server or rebuild after adding them.
